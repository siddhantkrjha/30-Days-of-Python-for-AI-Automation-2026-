# Security Policy

## Repository Access Policy

This repository is provided as part of the course:

**30 Days of Python for AI & Automation (2026)**

The repository serves as a learning resource containing:

- Lecture source code
- Practice exercises
- Portfolio project templates
- Course assets
- Reference materials

Students are granted read-only access to repository content.

---

## Allowed Actions

Students may:

- View repository files
- Download source code
- Clone the repository locally
- Open projects in Visual Studio Code
- Use GitHub Desktop
- Connect repositories to GitHub Codespaces
- Modify files on their personal machines
- Create personal forks for learning purposes
- Build personal portfolio projects based on course material

---

## Restricted Actions

Students are NOT authorized to:

- Push commits directly to the official repository
- Modify official course files
- Create branches within the official repository
- Submit unauthorized pull requests
- Remove copyright notices
- Redistribute course materials as their own
- Upload malicious code
- Abuse GitHub workflows or automation systems
- Attempt unauthorized access to repository settings

Only course administrators and repository maintainers may modify official course content.

---

## Repository Integrity

All official course code is maintained exclusively by repository administrators.

Students should treat the repository as a reference implementation and maintain their own versions of projects in separate repositories or local development environments.

Recommended workflow:

1. Clone repository
2. Open in VS Code
3. Complete exercises locally
4. Create personal portfolio projects
5. Push personal work to a personal GitHub repository

---

## Reporting Security Issues

If you discover:

- exposed credentials
- vulnerable dependencies
- accidental secrets
- security flaws
- unauthorized modifications

please report the issue privately.

Do NOT publicly disclose vulnerabilities until they have been reviewed.

---

## Response Timeline

Security reports are typically acknowledged within:

- Initial response: 3–7 business days
- Investigation: based on severity
- Resolution: dependent on complexity

---

## Responsible Disclosure

We appreciate responsible security research.

Please provide:

- detailed reproduction steps
- affected files
- screenshots if applicable
- suggested remediation if known

Reports that include sufficient technical detail can be investigated more efficiently.

---

## Student Reminder

This repository is intended for educational purposes.

Use the projects to learn, experiment, and build your own portfolio applications.

The strongest way to learn Python is to build your own solutions rather than only copying existing code.
